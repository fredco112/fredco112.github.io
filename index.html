Aurion

Ein MMORPG mit Expeditionen in prozedural generierte Welten, gemeinsam in der Gruppe oder allein. Jeder Run baut eine neue Welt, der Kampf ist schnell und lesbar, und die Stadt dient als Basis mit Händlern, Quests, eigenem Haus und Gilde.

An MMORPG with expeditions into procedurally generated worlds, in a group or solo. Every run builds a new world, combat is fast and readable, and the city is your base with merchants, quests, your own house and a guild.

System 1

Prozedurale WeltgenerierungProcedural world generation

Aus einem einzigen Seed entsteht eine komplette Welt: Biome mit weichen Übergängen, Flüsse und Seen, Hochebenen mit Rampen und ein Wegenetz.

A single seed produces a complete world: biomes with soft borders, rivers and lakes, plateaus with ramps and a road network.

  • Deterministisch: eigene Zufallsströme pro Schritt, damit jeder Client dieselbe Welt baut.
  • Planung auf Zellen, Ergebnis natürlich: Formen werden gerundet, das Raster ist nie zu sehen.
  • Datengetrieben: Look, Deko und Wetter kommen aus Biom-Assets (ScriptableObjects), nicht aus der Szene.
  • Rhythmus statt Masse: ein Planer läuft die Wege ab und setzt Begegnungen nur dort, wo zu lange nichts passiert.
  • Deterministic: separate random streams per step, so every client builds the same world.
  • Planned on cells, looks natural: shapes are rounded, the grid is never visible.
  • Data-driven: look, decoration and weather come from biome assets (ScriptableObjects), not from the scene.
  • Rhythm, not clutter: a planner walks the roads and only places encounters where nothing has happened for too long.
System 2

KampfsystemCombat system

Spieler und Gegner nutzen dieselben Ability-Komponenten. Der einzige Unterschied ist, wer sie steuert: die Eingabe des Spielers oder die Gegner-KI.

Players and enemies use the same ability components. The only difference is who drives them: player input or enemy AI.

  • Fähigkeiten als Daten: Effekte sind eigene ScriptableObject-Klassen, kein großer switch-Block.
  • Ehrliche Treffer: was der Telegraph zeigt, trifft, und zwar genau dann, wenn er voll ist.
  • Spielgefühl: Soft-Lock aufs Fadenkreuz, Tab-Lock, Hitstop und Kamera-Kick bei schweren Treffern.
  • Gegner-KI: Aggro durch Treffer, Leine, verzögertes Drehen, Flucht bei wenig Leben.
  • Abilities as data: effects are their own ScriptableObject classes, no giant switch block.
  • Honest hits: what the telegraph shows is what hits, exactly when it fills up.
  • Game feel: soft lock to the crosshair, tab lock, hitstop and camera kick on heavy hits.
  • Enemy AI: aggro from hits, leash, delayed turning, fleeing at low health.
System 3

TalentsystemTalent system

Ein Pfad-Baum pro Klasse, ein Punkt pro Level. Aktuell gibt es drei Klassen, weitere sind geplant. Talente ändern nie, wie ein Skill aussieht, sondern nur Zahlen, Bedingungen und Zusatzeffekte.

One path tree per class, one point per level. There are three classes right now, more are planned. Talents never change how a skill looks, only numbers, conditions and extra effects.

  • Kein Meta-Zwang: Jeder Pfad soll sich lohnen. Man muss gut überlegen, aber am Ende skillt man nach dem eigenen Spielstil, ohne gegenüber einem „besten“ Build benachteiligt zu sein.
  • Zentrale Modifier: der Kampfcode fragt an festen Stellen nach, statt Sonderfälle pro Talent zu kennen.
  • Erweiterbar: eine neue Talentart oder Bedingung ist eine neue Unterklasse.
  • Live-Tooltips: Skill-Tooltips rechnen den Schaden bei jedem Hover mit den aktuellen Werten des Spielers.
  • No forced meta: every path should be worth it. You have to think it through, but in the end you build for your own playstyle without falling behind a "best" build.
  • Central modifiers: the combat code asks at fixed points instead of knowing special cases per talent.
  • Extensible: a new talent type or condition is just a new subclass.
  • Live tooltips: skill tooltips recalculate damage on every hover with the player's current stats.
System 4

UI des gesamten SpielsThe whole game UI

HUD, Inventar, Charakter, Quest-Log, Weltkarte, Händler, Auktionshaus, Talente und Optionen. Alles in einem einheitlichen Stil und nach festen Regeln.

HUD, inventory, character, quest log, world map, merchants, auction house, talents and options. All in one consistent style and built on fixed rules.

  • Ebenen statt Sortierung von Hand: HUD < Fenster < Vollbild < Popups < Overlay.
  • Zonen: Meldungen, Kampffehler, Interaktion und Dialog haben feste Plätze und überdecken sich nie.
  • Frei belegbare Tasten: zentrale Eingabe-Schicht, die beim Tippen in Textfeldern das Spiel sperrt.
  • Editor-Tools: UI wird per Menüpunkt reproduzierbar ins Prefab gebaut, nicht zur Laufzeit.
  • Layers instead of manual sorting: HUD < windows < fullscreen < popups < overlay.
  • Zones: messages, combat errors, interaction and dialogue have fixed places and never overlap.
  • Rebindable keys: one central input layer that locks the game while you type in a text field.
  • Editor tools: UI is built into the prefab reproducibly from a menu item, not at runtime.
Wie ich arbeite: Rund 40 % des Codes von Aurion schreibe ich selbst, den Rest setze ich mit KI-Unterstützung (Claude Code) um. Spielidee, Systemdesign und Architektur kommen von mir, ebenso die Regeln, an die sich der Code halten muss. Jeden Code, auch den der KI, lese und prüfe ich und teste ihn im Editor.

Grafik: Modelle, Texturen, Animationen und ein Teil der Effekte stammen aus dem Unity Asset Store, manches ist noch Platzhalter. Weltgenerierung, Systeme, UI-Logik und eigene Shader (z.B. Wasser, Telegraph, HUD-Leisten) entstehen im Projekt selbst.
How I work: I write about 40% of Aurion's code myself and implement the rest with AI assistance (Claude Code). The game idea, system design and architecture are mine, as are the rules the code has to follow. I read and review every piece of code, including the AI's, and test it in the editor.

Art: models, textures, animations and some effects come from the Unity Asset Store, some things are still placeholders. World generation, systems, UI logic and custom shaders (e.g. water, telegraph, HUD bars) are built in the project itself.
